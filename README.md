# PyBot

A small chatbot I made in Python that runs in the terminal. It can say hello, tell you its name, and give you the current time and date in Pakistan. It keeps running until you type `bye`.

I made this while learning Python, mostly to practice loops, `if/elif` statements and the `datetime` module.



## What you can say

The bot looks for certain words in what you type, so you don't have to type the exact sentence.

- `hello` - it greets you
- `how are you` - it tells you how it's doing
- `name` - it tells you its name
- `time` - it shows the current time (Pakistan time)
- `date` - it shows today's date
- `help` - it shows a list of things to try
- `bye` - it closes the program

Anything else and it will just say it doesn't understand.
